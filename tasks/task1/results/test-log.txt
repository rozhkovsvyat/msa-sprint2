== Проверка кодовой базы ==
-- скидка промокода вычитается как сумма, а сохраняется как процент:
51:        double finalPrice = basePrice - discount;
58:        booking.setDiscountPercent(discount);
-- базовая цена зависит только от статуса пользователя, не от отеля:
95:            return isVip ? 80.0 : 100.0;
-- createdAt в createBooking не заполняется:
   вызовов setCreatedAt в BookingService: 0
-- срок действия промокода (validUntil) не проверяется, только флаг expired:
22:                .filter(p -> !p.isExpired())
-- схема БД пересоздаётся при каждом старте:
8:      ddl-auto: create
-- готовый gRPC-прокси (libs/p-o-y-1.0.0.jar, без исходников), javap GrpcBookingService.toBooking:
   14: invokevirtual #124                // Method java/lang/String.isBlank:()Z
   22: invokestatic  #128                // Method java/lang/Long.parseLong:(Ljava/lang/String;)J
   82: invokestatic  #179                // Method java/time/Instant.parse:(Ljava/lang/CharSequence;)Ljava/time/Instant;
   => id проверяется на пустоту, created_at разбирается всегда: пустая дата из нового сервиса даст 500.
